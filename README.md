# 最后一公里 · 三套建站提示词

《AI 建站最后一公里》第 2 期的三套提示词：网站、微信小程序、App。

## 怎么用

1. 选一套，整段复制到 AI 对话工具里。
2. 填三个空：你想做什么、主要给谁用、必须具备的功能。
3. 回答 AI 的问题，确认它给出的方案，再让它开工。
4. 做完自己验一步：记一笔账，刷新一下页面，账还在，才算数。

## 三套的区别

| 文件 | 适合做什么 |
|---|---|
| Web网站提示词.md | 网站、Web 应用。分交互应用和公开内容网站两条路线。 |
| 微信小程序提示词.md | 微信小程序。默认自建路线；轻量第一版也可走云开发路线，方案阶段由你拍板。 |
| 移动端App提示词.md | Android、iOS 双端 App。Web 技术加壳，一套代码出两个端。 |

三套骨架一样：先对需求、选型写死、给 AI 立规矩、最后交付完整代码和清单。技术选型已经固定好，适合不懂技术的新手直接用。
